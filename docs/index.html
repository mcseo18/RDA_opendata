농업 기술정보 통합 포털

농촌진흥청 농사로(Nongsaro) 및 국립원예특작과학원에서 제공하는 영농기술, 작목별 재배관리, 주간농사정보, 원예·특용작물 연구동향 데이터를 체계적으로 수집·정리하여 스마트팜 운영자와 농업 연구자가 빠르게 검색하고 활용할 수 있도록 지원합니다.

연계 API 목록 보기 서비스 운영 정보

주요 서비스 기능

공공 농업 데이터를 현장 친화적인 검색·의사결정 정보로 통합 제공합니다.

재배 · 영농기술

농사로 영농기술 및 작목정보

작목별 농업기술길잡이, 주간농사정보, 병해충 및 생리장해 관리 자료를 연계하여 시기별·작목별 핵심 영농 정보를 한눈에 확인할 수 있습니다.

원예 · 특용작물

연구동향 및 기술정보 아카이브

국립원예특작과학원의 과수·채소·화훼·특용작물 연구동향과 기술정보 원문을 메타데이터와 함께 구조화하여 빠르고 정확한 문서 검색을 지원합니다.

스마트팜 의사결정

AI 기반 농업 지식 검색(RAG)

수집된 공식 연구·기술 문서를 바탕으로 출처(자료명, 발행기관, 쪽수)가 명확한 스마트팜 재배 관리 질의응답 및 참고자료 추천 시스템을 구축하고 있습니다.

연계 대상 공공 Open API

본 서비스는 아래의 농촌진흥청 및 공공데이터포털 Open API를 활용합니다.

제공 기관 / 플랫폼 API 서비스명 활용 목적 상태
농촌진흥청 농사로 (nongsaro.go.kr) 영농기술 · 농업기술길잡이 · 주간농사정보 · 작목정보 Open API 작목별 재배 매뉴얼 및 시기별 영농정보 제공 연계 준비중
공공데이터포털 (국립원예특작과학원) 원예특작 연구동향 조회 서비스 원예·특용작물 최신 연구동향 자료 수집 및 검색 연계 중
공공데이터포털 (국립원예특작과학원) 원예특용작물 기술정보 조회 서비스 과수·채소·화훼·특용작물 기술정보 통합 아카이브 연계 중

공공데이터 출처표시 및 저작권(공공누리) 준수 안내

본 서비스에 활용되는 모든 농업 기술자료 및 연구동향 데이터의 저작권은 농촌진흥청(국립원예특작과학원, 농사로) 및 해당 원저작기관에 있습니다. 본 포털은 공공데이터 제공 정책과 공공누리(KOGL) 이용허락범위를 준수하며, 모든 조회·검색 결과에 원문 출처(자료명, 발행기관, 원문 링크)를 명확히 표기합니다.
